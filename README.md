# CBRE-Style Corporate Authentication System

A full-stack authentication system inspired by CBRE's design language.

## Tech Stack
- **Frontend**: React.js, Tailwind CSS v4, Framer Motion, Lucide Icons
- **Backend**: Node.js, Express, MongoDB, Nodemailer, JWT

## Project Structure
- `/New Benjwa fronted`: React application
- `/New Bejnwa Backend`: Express API

## Features
- Signup with strict validation
- 6-digit OTP verification via Gmail
- Secure Login with JWT
- Protected Dashboard
- Dark Mode support

## Setup
1. Clone the repo
2. Install dependencies in both folders (`npm install`)
3. Set up `.env` in the backend folder
4. Run `npm run dev` in frontend and `node server.js` in backend.
